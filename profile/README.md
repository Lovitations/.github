# Lovitations

Digital save-the-dates, wedding invitations and wedding websites, with a
personal link for every guest, a live RSVP dashboard and day and evening
guests built in. → [lovitations.nl](https://lovitations.nl)

## Plugin for AI assistants

[**lovitations/public**](https://github.com/lovitations/public): wedding
planning skills for Claude, ChatGPT and Codex, Gemini CLI and Grok Build.
Invitation wording, wedding website copy, a guest list with headcounts, RSVP
follow-up, a seating plan, a schedule for the day, a budget and speeches, in
the language you write in.

```
/plugin marketplace add lovitations/public
/plugin install lovitations@lovitations
```
